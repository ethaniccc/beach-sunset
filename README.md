# Beach sunset

A theme for the Claude Code desktop app. It puts a late sunset over a tropical island bay behind your chat. The picture looks like colored pencil on rough paper, and it is drawn by JavaScript when the theme loads. There is no image file.

## What you get

- A sunset background: mountains on both sides, palms, a bay, clouds and the first stars.
- Hand-drawn movement, where the app allows it: the water rocks, the sun's path sparkles, clouds drift, stars blink, and the palms and grass sway.
- See-through navy panels, so the picture shows behind the chat.
- A rounded box around each of Claude's replies.
- Dark colors to match. The theme is made for dark mode only.

## Install

In the desktop app: click + next to the prompt box, then Plugins, then Add marketplace with `ethaniccc/beach-sunset`, then Add plugin.

At the prompt of a terminal session:

```
/plugin install beach-sunset --marketplace ethaniccc/beach-sunset
```

From a shell:

```
claude plugin install beach-sunset --marketplace ethaniccc/beach-sunset
```

Then restart the app, open a thread and send a message. The background shows after the first message.

## Good to know

- It needs a version of the Claude desktop app that draws a mod's backdrop behind the chat. The terminal shows no background.
- A brand new thread shows no background until you send a message.
- Whether the picture moves depends on the app. On some setups the app holds a background still.

## Turn it off

```
claude plugin disable beach-sunset
```
